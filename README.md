# Цифровой Казахстан 2050 — сайт для Render

Сайт с картой, QR-кодом и опросом. Опрос хранит ответы в Postgres, поэтому результаты общие для всех посетителей и вход в Claude не нужен.

## Как выложить на Render

1. **Загрузите папку на GitHub** (новый репозиторий, файлы в корне).
2. **Создайте базу Postgres.**
   - Бесплатно и без срока: Neon (neon.tech). Создайте проект и скопируйте строку подключения `postgresql://...`.
   - Или Render → New → PostgreSQL. На бесплатном тарифе такая база удаляется через 30 дней после создания.
3. **Render → New → Blueprint** (или Web Service) и выберите репозиторий.
   - Build Command: `npm install`
   - Start Command: `npm start`
4. В **Environment** добавьте `DATABASE_URL` со строкой подключения из шага 2 и нажмите Deploy.
5. Откройте `https://<имя-сервиса>.onrender.com`. QR-код на сайте автоматически ведёт на этот адрес.

Если `DATABASE_URL` не задан, ответы пишутся в файл `data/votes.json`. Это удобно для проверки на компьютере, но на бесплатном Render файл стирается при перезапуске.

## Локальный запуск

```
npm install
npm start
```
Сайт откроется на http://localhost:3000.

## Как это устроено

- `public/index.html` — весь сайт (карта, вкладки, опрос).
- `server.js` — Express: отдаёт сайт и API `GET/POST /api/votes`.
- Один ответ на устройство: повторная отправка заменяет прежний ответ. Не более 10 отправок в минуту с одного адреса.
- Бесплатный сервис Render засыпает после 15 минут без посетителей, первое открытие после паузы занимает около минуты.
